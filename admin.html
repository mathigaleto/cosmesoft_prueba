ACCESO ADMINISTRATIVO

Ingresar al panel

La página pública sigue abierta para todos. Este acceso es solo para la cuenta administradora autorizada.

Para iniciar normalmente usá cosmesoft-admin y tu contraseña; no se envía un correo en cada ingreso. Si todavía no configuraste contraseña, usá el botón de una sola vez. El enlace de correo puede estar sujeto al límite de envíos de Supabase.

Personas detrás de cada solución

La web mostrará una sección con las personas que agregues. El cargo puede dejarse vacío. Atajo: pulsá espacio dos veces para insertar cada separador automáticamente; también podés escribir |.Elegí varias fotos. Se agregan con el nombre del archivo; editá nombre y cargo antes de guardar.
